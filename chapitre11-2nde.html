🎯 Objectifs du chapitre
  • Savoir calculer la masse d'une entité (atome, ion, molécule)
  • Savoir calculer le nombre d'entités N dans un échantillon
  • Savoir calculer une quantité de matière n à l'aide de la constante d'Avogadro

1. Masse mentité d'une entité

📘 Définition La formule brute d'une entité (atome, ion ou molécule) est l'écriture la plus compacte décrivant la nature et le nombre des atomes de cette entité. La masse mentité d'une entité est égale à la masse des atomes qui la composent.

Exemple : la molécule de dioxyde de carbone CO₂ contient 1 atome de carbone et 2 atomes d'oxygène. m(CO₂) = mC + 2×mO = 2,00×10⁻²⁶ + 2×2,67×10⁻²⁶ = 7,35×10⁻²⁶ kg.

👉 Bascule entre plusieurs molécules : observe la masse se recalculer.

2. Nombre d'entités N

📘 Définition Le nombre d'entités N dans un échantillon est le quotient de la masse m de l'échantillon (en kg) par la masse mentité d'une entité (en kg). N est sans unité.
N = mmentité

Exemple : dans un échantillon de dioxyde de carbone de masse m = 10 kg, N = 10/(7,35×10⁻²⁶) ≈ 1,4×10²⁶ molécules.

👉 Règle la masse de l'échantillon de CO₂ : observe N se calculer.

3. Quantité de matière n

📘 Définition Une mole d'entités d'une espèce est un « lot » de 6,02×10²³ entités. La constante d'Avogadro NA est le nombre d'entités dans une mole : NA = 6,02×10²³ mol⁻¹.

La quantité de matière n représente le nombre de « lots » (de moles) présents dans l'échantillon.

n = NNA

Exemple : avec N ≈ 1,4×10²⁶ molécules de CO₂, n = N/NA = 1,4×10²⁶ / 6,02×10²³ ≈ 2,3×10² mol.

👉 Règle l'ordre de grandeur de N : observe n se calculer.
